# Giant Manual Finance Core

A comprehensive, large scale wealth management dashboard built entirely in flat Python code. This project is specifically architected for beginners who want to study a large project without getting lost in advanced syntax.

## Structural Design
To maximize readability and keep the code completely clean, this project strictly follows these design constraints:
* **No Custom Functions:** Avoids the use of def or return statements so code execution flows straight down from top to bottom.
* **No Clutter Symbols:** Written without using a single hashtag (#) or underscore (_) throughout the entire codebase.
* **Simple Data Output:** Uses plain print styling instead of complex string formatting techniques.

# Features
1. **Initial Account Balances:** Manually input and track your wallet cash, bank accounts, and emergency funds.
2. **Fixed Monthly Obligations:** Step by step tracking for your primary bills like rent, utilities, internet, and insurance.
3. **Outstanding Debt Trackers:** Log your liability data including credit cards, student loans, and vehicle loans.
4. **Manual Variable Expense Logging:** Enter individual daily spending transactions using a simple command line loop interface.
5. **Savings Goal Checker:** Estimate exactly how many months it will take to secure your next big financial target.
6. **Master Health Status:** Generates a unified overview computing your actual net worth, total outflows, and cash surpluses or deficits.

## How to Run
1. Ensure you have Python installed on your system.
2. Download or clone this script file.
3. Open your terminal or command line application.
4. Navigate to the project directory and run:
   `python filename.py`
